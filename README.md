# PWA Посещаемость группы

Офлайн-приложение для учета посещаемости. Все записи сохраняются локально в браузере (localStorage); сервер, аккаунты и синхронизация не используются.

## Возможности
- Первоначальная настройка группы и списка студентов.
- Сортировка ФИО по алфавиту.
- Месячная таблица с закрепленным столбцом студентов и горизонтальной прокруткой.
- Цикл отметок: присутствует → отсутствует → болеет → пусто. Пустая отметка учитывается как присутствие.
- Счетчики выбранного дня.
- Статистика за месяц до выбранной даты, дневная таблица и статистика по студенту.
- Экспорт месячной таблицы в CSV (открывается в Excel).
- JSON-резервная копия и импорт.
- Выбор месяца; число дней определяется календарем (28–31).
- PWA-установка и offline shell cache.

## Размещение на GitHub Pages
1. Создайте репозиторий и загрузите все файлы из архива в корень.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch; Branch: `main`; folder: `/ (root)`.
4. Сохраните. Откройте ссылку GitHub Pages. Для установки PWA нужен HTTPS (GitHub Pages его предоставляет).
5. На iPhone: открыть сайт в Safari → Поделиться → На экран «Домой».

## Важно
- Данные хранятся в локальном профиле браузера и не синхронизируются между устройствами.
- Не очищайте данные сайта, если не сделали JSON-резервную копию.
- CSV экспортирует месячную сетку и предназначен для открытия в Excel.

## Дальнейшие расширения
В текущем проекте гибкий список участников и отметок, а расписание занятий с названиями пар/окон не является отдельным измерением: таблица учета посещаемости рассчитана на дни месяца, не на пары.
